## 一、行业认知

### 核心概念速记

- **三大岗位模块**：大模型应用开发（需求量大、门槛低、最适合转型）、模型层（技术核心、门槛高）、基础设施层（稳定需求）
- **主流语言选择**：Java是生产环境主流，Python适合研究原型阶段；想就业选Java+AI
- **公司类型**：
  - 巨头（OpenAI、百度、阿里、智谱AI）：技术导向，考察项目深度
  - AI原生应用公司（Notion、Midjourney）：项目+思维，看重解决实际问题能力
  - 行业巨头/传统企业：业务+实操，希望快速理解业务并带来价值
- **学历要求**：AI应用开发岗位专科及以上学历即可
- **转型周期**：有编程基础约1-4个月，零基础约5个月
- **薪资水平**：12K-45K，资深人才25-45K，掌握高端技能可达80万+年薪

### 高频问题答案要点

1. **为什么选择大模型应用开发方向？**
   - 岗位多、入行门槛低、风口期、薪资普遍高于传统开发

2. **Java和Python在AI开发中的区别？**
   - Java：成熟企业级生态、工程体系完善、性能优势，生产环境主流
   - Python：灵活易用、适合研究原型、入门简单

3. **不同类型公司的面试风格？**
   - 巨头：技术导向，问原理和项目深度
   - AI原生：围绕项目经验，看解决问题能力和产品思维
   - 传统企业：务实，关注业务理解和技术落地价值

## 二、RAG检索增强生成

### 核心概念速记

- **定义**：检索外部信息（内部知识库+联网搜索），增强AI回答精准度
- **核心流程**：信息→向量化→向量数据库存储→检索→增强生成
- **关键技术**：
  - Embedding：文本转向量（BGE、text-embedding-3-large、m3e、multilingual-e5）
  - 向量数据库：Milvus、PGVector、Qdrant、Weaviate、Chroma
  - 检索策略：混合检索（关键字+向量）、Query Expansion、Rerank
  - 文档处理：语义拆分、递归拆分、中文专属拆分
  - 评估指标：准确率、引用率、幻觉率、响应时延

### 高频问题答案要点

1. **RAG完整工作流程？**
   - 文档加载→文本拆分→向量化→向量存储→用户查询→检索→重排序→生成回答

2. **为什么需要RAG？**
   - 解决大模型幻觉问题，提供准确可追溯的信息，支持私有知识库

3. **常见分块策略？**
   - 语义拆分（按语义边界）、递归拆分（多层级）、固定长度+重叠

4. **向量数据库选型因素？**
   - 数据规模、查询速度、部署成本、生态兼容性

5. **RAG幻觉治理方法？**
   - 引用标注、检索增强、重排序、提示词约束、输出过滤

## 三、Agent智能体

### 核心概念速记

- **定义**：具备自主决策能力的AI系统，包含记忆和工具调用能力
- **核心组件**：LLM、记忆系统、工具调用、规划能力
- **主流框架**：LangChain、AutoGPT、MetaGPT、OpenClaw
- **关键技术**：
  - 记忆管理：短期记忆（上下文窗口）、长期记忆（数据库持久化）
  - 工具调用：Function Calling、MCP协议
  - 推理模式：ReAct（思考-行动）、CoT（思维链）
  - 多Agent协作：路由模式、编排模式、并行化模式

### 高频问题答案要点

1. **Agent与直接调用大模型API的区别？**
   - Agent具备自主决策、工具调用、记忆能力，能完成复杂多步骤任务

2. **Agent核心工作流程？**
   - 接收任务→规划步骤→调用工具→观察结果→反思优化→输出结论

3. **短期记忆与长期记忆的差异？**
   - 短期：利用上下文窗口，有限容量；长期：存储到数据库（Redis/MySQL），可持久化

4. **工具调用完整链路？**
   - 定义工具Schema→LLM识别工具→参数推理→执行工具→解析结果→生成回答

5. **Agent死循环问题解决方法？**
   - 设置最大迭代次数、状态检查、人工干预、反思机制

## 四、大模型微调

### 核心概念速记

- **定义**：在预训练模型基础上，用特定领域数据进一步训练
- **常见方法**：全量微调、LoRA（低秩适配）、QLoRA、PEFT
- **关键参数**：learning rate、batch size、epochs、LoRA rank
- **流程**：数据准备→数据清洗→模型选择→训练→评估→部署
- **评估指标**：loss、准确率、BLEU、ROUGE

### 高频问题答案要点

1. **微调与预训练的核心差异？**
   - 预训练：学习通用知识；微调：适应特定领域任务

2. **LoRA原理？**
   - 通过低秩矩阵近似替代全量参数更新，降低计算成本，保持模型性能

3. **PEFT三种典型方法？**
   - LoRA（低秩适配）、Adapter（适配器层）、Prefix Tuning（前缀微调）

4. **微调数据构建方法？**
   - 开源数据集、自定义数据采集、数据清洗与格式化

5. **灾难性遗忘防范方法？**
   - 混合训练、正则化、参数冻结、增量学习

## 五、协议与框架

### 核心概念速记

#### 协议
- **MCP协议**：大模型调用外部工具的标准化协议，支持STDIO、SSE、HTTP传输
- **A2A协议**：Agent间通信协议，五大设计原则

#### 框架
- **Spring AI**：Java生态AI框架，核心抽象AIClient→ChatClient→EmbeddingClient→VectorStore
- **LangChain**：Python生态AI框架，核心组件Chain、Agent、Memory、Retriever
- **LangGraph**：基于LangChain的状态机框架，支持复杂业务流程编排
- **关键技术**：护栏技术、GPTCache、结构化输出

### 高频问题答案要点

1. **MCP协议与Function Calling的差异？**
   - MCP是标准化协议，一套工具适配多个大模型；Function Calling是特定模型的调用方式

2. **Spring AI核心抽象？**
   - AIClient（统一抽象）→ChatClient（对话）→EmbeddingClient（向量化）→VectorStore（向量存储）

3. **LangChain核心组件？**
   - Chain（链式调用）、Agent（智能体）、Memory（记忆）、Retriever（检索器）、PromptTemplate（提示词模板）

4. **LangChain与LangGraph差异？**
   - LangChain：线性链式调用；LangGraph：状态机驱动，支持复杂分支和循环

5. **结构化输出实现方式？**
   - Pydantic/Python、Java Record、ResponseFormat约束

## 六、提示词工程

### 核心概念速记

- **定义**：设计和优化提示词以引导AI输出高质量结果
- **关键技术**：
  - Few-shot Learning：零样本、单样本、少样本学习
  - CoT：思维链，引导逐步推理
  - ToT：思维树，探索多种推理路径
  - 角色扮演：设定AI角色身份
  - 自洽性：多次采样选择一致答案
- **参数控制**：temperature（创造性）、top_p（核采样）、presence_penalty（重复惩罚）

### 高频问题答案要点

1. **减少幻觉的Prompt设计方法？**
   - 要求引用来源、提供上下文信息、设置约束条件、要求结构化输出

2. **CoT工作原理？**
   - 引导模型"一步步思考"，在提示词中加入"让我仔细思考"等引导语

3. **temperature与top_p作用？**
   - temperature：控制输出随机性，越高越多样；top_p：控制核采样范围，越小越集中

4. **System Prompt与用户Prompt差异？**
   - System Prompt：设定AI角色和行为准则；用户Prompt：具体任务指令

5. **Prompt Injection防范方法？**
   - 输入校验、分隔符使用、防御性Prompt、输出过滤

## 七、Transformer与基础模型

### 核心概念速记

- **核心架构**：Encoder（编码）+ Decoder（解码）
- **关键机制**：
  - 多头注意力：并行计算多个注意力头
  - 残差连接：缓解梯度消失
  - Layer Normalization：加速收敛
  - 位置编码：注入位置信息
- **主流模型**：GPT（Decoder-only）、BERT（Encoder-only）、LLaMA、ChatGLM
- **性能优化**：梯度裁剪、混合精度训练、Flash Attention

### 高频问题答案要点

1. **Transformer解决RNN什么问题？**
   - 并行计算能力、长距离依赖建模、恒定时间复杂度

2. **多头注意力作用？**
   - 同时关注不同位置、不同语义关系，增强表达能力

3. **残差连接作用？**
   - 缓解梯度消失，允许信息直接传递

4. **位置编码方式？**
   - 正弦位置编码、学习位置编码、旋转位置编码（RoPE）

5. **GPT与BERT差异？**
   - GPT：Decoder-only，自回归生成；BERT：Encoder-only，双向理解

## 八、NLP自然语言处理

### 核心概念速记

- **词嵌入**：Word2Vec、GloVe、BERT Embedding
- **序列模型**：RNN、LSTM、GRU
- **预训练模型**：BERT、GPT、ELMo
- **关键技术**：
  - 注意力机制：聚焦重要信息
  - 文本分类：情感分析、意图识别
  - 文本生成：摘要、翻译、问答

### 高频问题答案要点

1. **LSTM核心组成？**
   - 输入门、遗忘门、输出门、单元状态

2. **BERT架构？**
   - Transformer Encoder堆叠，Masked LM训练，双向上下文理解

3. **Word2Vec两种模式？**
   - CBOW：上下文预测中心词；Skip-gram：中心词预测上下文

4. **注意力机制作用？**
   - 允许模型在处理每个位置时关注输入序列的不同部分

5. **文本分类样本不平衡处理？**
   - 过采样、欠采样、加权损失函数、数据增强

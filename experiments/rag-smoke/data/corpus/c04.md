# 存储层次与 Cache

存储器按速度和容量分层：寄存器最快最小，然后是高速缓存 Cache、主存（内存），最后是磁盘等外存。越往上越快越贵，越往下越慢越大。

CPU 与内存之间存在速度差距，Cache 用少量 SRAM 保存最近使用的主存数据副本。CPU 先查 Cache，命中就直接用，未命中才去主存取，并把整块数据调入。程序访问具有局部性：刚用过的数据附近的数据很可能马上被用到（空间局部性），刚用过的数据本身很可能再次被用（时间局部性），这是 Cache 有效的原因。

硬件 Cache 由 CPU 自动管理，对程序透明。写策略有写直达和写回两种：写回只在数据被替换出 Cache 时才写主存，减少访存次数但实现更复杂。

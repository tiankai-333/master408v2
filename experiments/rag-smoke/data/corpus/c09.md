# HTTP 与 HTTPS

HTTP 是应用层的超文本传输协议，本身明文传输。HTTPS 是 HTTP 加上 TLS 加密层：先经 TLS 握手协商密钥，之后的数据都加密传输，防止窃听和篡改。

HTTPS 依靠证书验证服务器身份。服务器把证书发给客户端，证书里有公钥和域名信息，并由证书颁发机构（CA）的私钥签名。客户端用内置的 CA 根证书验签，确认"这个公钥确实属于这个域名"。证书校验失败时浏览器会告警，这就是自签名证书要手动信任的原因。

TLS 握手用非对称加密交换材料，之后的会话用对称加密，因为对称算法快得多。HTTP 默认端口 80，HTTPS 默认 443。

浏览器会把网页的静态资源存在本地缓存，并用 Cache-Control 等响应头控制有效期；这与服务器端加密是两回事，前者省流量，后者保安全。

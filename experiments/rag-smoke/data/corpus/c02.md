# 原码、反码与补码

计算机里带符号整数常用补码表示。原码是"符号位加绝对值"；正数的反码与原码相同，负数的反码是符号位不变、其余各位取反；负数的补码是反码加 1。正数的补码等于原码。

补码的好处是减法可以当加法算：a - b 等价于 a 加上 b 的补码，CPU 只需要一套加法器。8 位补码能表示 -128 到 127，其中 10000000 约定为 -128，没有对应的原码。

求负数补码的另一种口诀：从右往左找到第一个 1，它左边（更高位）全部取反。例如 -52 的 8 位补码：52 是 00110100，取反得 11001011，加 1 得 11001100。

补码中 0 只有一种表示（全 0），这也是它优于原码、反码的原因之一。

# 二进制与进制转换

计算机内部用二进制表示数据，因为电路只有高低两种电平，分别对应 0 和 1。

十进制整数转二进制用"除 2 取余、逆序排列"：把数不断除以 2，记录余数，直到商为 0，再把余数从下往上读。例如 13 转二进制：13÷2 余 1，6÷2 余 0，3÷2 余 1，1÷2 余 1，得 1101。

二进制转十进制按位权展开：每一位乘以 2 的相应次幂再求和。1101 就是 1×8 + 1×4 + 0×2 + 1×1 = 13。

二进制转十六进制每 4 位一组，从右往左分组，每组换成一个十六进制数字；转八进制则每 3 位一组。十六进制常用于缩写长的二进制串，一位十六进制正好对应 4 位二进制。

# 死锁及其必要条件

死锁指一组进程互相持有对方需要的资源、都无法继续推进的状态。产生死锁有四个必要条件，缺一不可：

1. 互斥：资源同一时刻只能被一个进程占有。
2. 占有并等待：进程占有部分资源的同时还在等待其他资源。
3. 不可剥夺：资源只能由占有者主动释放，不能被强行抢走。
4. 循环等待：存在进程环形链，每个都在等下一个持有的资源。

破坏任意一个条件就能预防死锁，例如规定进程一次性申请全部资源（破坏占有并等待），或给资源编号、只能按序申请（破坏循环等待）。

死锁避免的典型算法是银行家算法，在分配前判断系统是否仍处于安全状态。死锁发生后的处理包括终止部分进程或强制剥夺资源；检测到死锁再处理，代价是可能已有进程长期阻塞。

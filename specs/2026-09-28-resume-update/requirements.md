# Requirements — 简历更新与面试证据对齐

## 目标与范围

基于现有简历与真实工程证据，更新可投递的简历版本，并让作者能够独立解释每条核心经历。面向软件工程相关岗位，不自动限定为 Agent 岗，也不为投递补造功能或指标。本次先建立规格，简历正文与 PDF 更新属于后续执行。

根目录：[面试资料/resume](../../面试资料/resume/)。以下为现有材料的表述，不代表本轮已独立核验教育、任职或外部项目事实。

- 教育：东华大学软件工程本科，2023.09—2027.06，2027 届。
- 实习：上海支点撬动人工智能科技有限公司，AI 应用开发，2026.07—2026.08；GEO 搜索排名分析、异步任务、桌面发布、权限隔离及部署。
- 项目：408Master 与 StoryCraft Game。
- [版本治理](../../面试资料/resume/agent-app-intern-detailed/全量简历用语审查与版本治理.md)指定：`agent-app-intern-detailed` 为两页主版本，`agent-app-intern` 为一页精简版，`ai-fullstack-intern-v2` 为有效全栈版；其余历史版本仅作参考。

| CV-03 | 核对 9 月新增候选成果：双端账户隔离、数据库契约设计、管理端设计、公网部署及联合实施实际进度。仅选择有证据且作者能说明价值的内容，不把所有 Feature 塞入简历。 |
| CV-04 | 每条表述优先说明业务问题、个人动作、技术选择与结果；不堆术语，不把测试数量写成覆盖率，不把规则评分写成人工质量评分，不把上线写成全部功能可用。 |
| CV-05 | 教育、任职时间、角色、求职意向和个人信息由用户确认；不自动更新联系方式。演示地址逐项核查可达性及实际能力，旧 v1 与新 v2 地址不能直接互换。 |
| CV-06 | 复用既有 TeX 排版和字体；生成目标页数 PDF 并逐页检查溢出、断页、字号、链接和文本提取顺序；源码与导出内容一致。 |
| CV-07 | 投递材料与内部证据分离；PDF 不带台账、未确认占位、密钥或公司内部信息。缺证据项删减或降级措辞，不用模糊强词掩盖。 |
| CV-08 | 每项核心经历准备问题→动作→取舍→验证→局限的追问链；作者独立说明与实践通过后才确认该版本可投递，未掌握项补学、删减或改写。 |

## 非目标与交付物

### 目标方向补充（2026-09-30 用户确认）

简历满意目标改为“面向 408 学习的知识库 Agent”，重点是数据库设计与 RAG 测评集、意图识别与工具调用及有界 Loop、线上部署与小程序。保留历史工程演进，不以近期单一缺陷定义项目。
新增[目标态简历](../../面试资料/resume/knowledge-agent-target/目标简历.md)，独立于可投递版本；正文使用明确的目标标识，附 roadmap/证据差距。不把计划写成现状，不虚构指标。完整 Loop 的具体规格与数据库路线分叉仍需单独定稿，本次写简历不授权实施。

不投递职位、不联系招聘方、不虚构经历、不修改业务代码来凑简历、不自动新增岗位版本、不购买服务或调用付费模型。

交付为：更新后的既有证据台账与版本定位、经确认的 TeX 源码和按日期归档的 PDF、面试追问及自我考核记录。进度统一记入 roadmap；建立本规格不代表已开始正文改写或完成验收。

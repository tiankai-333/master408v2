# Plan — 新库与管理端联合实施

执行顺序：**0 边界定稿 → 1 空库引导 → 2 管道与版本 → 3 管理端主闭环 → 4 作答与检索 → 5 首版补齐与验收**。
每批完成后留下可复现证据；进度记入 roadmap，不因文档写出就认定实现完成。

## 批次 0：锁定环境与实施契约

- 只读核对两份设计与当前代码，产出需求→表/服务/API/页面→测试映射；复核最新 D-29～D-31，不执行旧迁移计划。
- 将 requirements 六项开工细节定稿，建立旧/新/沙箱连接矩阵及最小初始化清单。
- 明确账号权限、作业状态机、确认/幂等/重试协议与结构；补齐知识点标注、发布入口。
- 明确新端生产 base path 与路由配置，不能简单将 `/admin-next/` 产物改反代到 `/admin/` 就假设可用。

出口：接口、DDL 和环境边界可直接用于编码；有歧义的受影响项不进入下一批，其余可独立推进。

## 批次 1：空库引导与数据约束（IA-01/02）

- 为新库配置独立迁移链，建立必要业务表与候选 1～11；不修改旧迁移校验和，不依赖旧库 dump。
- 建立作业及逐题明细、批次血缘、attempt 版本映射所需结构，生成字段字典和约束错误映射。
- 配置最小权限连接、隔离测试保护、最小管理员/学科初始化；新环境启动时明确输出脱敏环境标识。
- 从空库运行两次引导，检查 schema/history 一致性、越权拒绝及对账查询；复核生成列唯一索引和访问计划。

出口：空库可启动，新旧环境不可误连；结构约束有真实 MySQL 测试，不用 mock 代替。

## 批次 2：采集管道、版本与作业（IA-03/04/05）

- 从小规模授权采集结果/原创夹具起步，实现标准化适配器、块/资源/来源校验及纯文本派生。
- 建立唯一的内容写服务；同事务锁题目、比较版本、写新版本和来源资源、更新 current 与作业明细。
- 实现 dry-run、人工确认、commit、jobs、detail 和薄 CLI；凭据经安全配置注入，不接受 AI 直连写库。
- 实现稳定来源键去重、同键异载荷拒绝、原结果重放、显式失败项重试、中断恢复；成功项不得再执行。
- 注入中途异常、重复提交、并发写与崩溃恢复，验证单题失败不影响其他题，成功记录与内容不会脱节。

出口：一小批题从采集载荷到新库可追踪、可重试；重导入产生正确版本，旧库无写入。

## 批次 3：管理端可审阅的主闭环（IA-06/07/10）

- 在 `admin-next` 建工程壳、admin 登录、导航、API Client、双层错误处理、401 单例跳转和 requestId。
- 先联调登录→工作台→题目列表→只读预览；空态、失败、缺资源与未就绪均显式展示。
- 完成来源资源面板、版本历史、作业列表/详情、确认与失败项重试，形成“校验→确认→写入→预览验收”闭环。
- 接通停用/恢复/紧急撤下、发布操作和知识点人工整理；前端不自行推断状态或提供题目内容编辑。
- 内容 HTML/内联资源按可信来源与安全渲染策略处理，测试脚本注入及越界资源引用。

出口：用户能从管理端确认一次真实管道作业，并定位每题来源、版本、写入批次和失败原因。

## 批次 4：作答版本与 RAG 消费（IA-08/09）

- 在新环境实现开始作答、恢复、交卷、判分及答卷详情；绑定不可变版本，防止刷新重建绑定。
- 调整新环境题目读取、选题和错题历史路径；只做学生端必要适配，不把旧库记录迁入新库。
- RAG 消费 canonical 内容，写入源版本/块/规则/hash，拆分展示与检索状态、补齐对账及失败重建。
- 联调 P5 RAG 状态与 P8 答卷详情；分别测词法、向量不可用、旧投影过滤及停用题处理。

出口：同一道题重导入更新后，旧 attempt 的题面与评分不变，新的检索结果不冒充旧/新版本。

## 批次 5：完整首版、回退与自我考核（IA-06/11/12）

- 完成页面矩阵其余项：试卷/任务、模型用量、Prompt Studio、固定评测、账户、学科、消息、操作日志；复用接口但逐项验证新库适配。
- 全量核对 P1～P17（P3 排除）；依赖未实现的页面不可标完成，更不能用禁用按钮冒充整体交付。
- 验证新旧环境共存、双端会话隔离、构建产物路径、重启恢复；演练停止管道与应用回退，保留新库新增事实。
- 整理发布交接与回退包：版本、配置键、库对应关系、兼容范围、恢复点和验证记录。实际公网切换须另获确认，不与本地联调混记。
- 完成 validation 和作者自我考核；同步 roadmap 与有关技术债，原设计只作索引引用，不覆盖旧实验事实。

出口：新链路完整可运行，首版无未交付页面；技术验收与考核分别记录。公网未切换时明确标“本地/隔离环境验收”，不声称线上已替换。

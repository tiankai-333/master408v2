# Validation — RAG 检索评测与问答闭环

以下为验收方向，尚未运行。实施前把当前步骤细化为可执行场景。

| 检查 | 应有证据 |
| --- | --- |
| 数据与标注可信 | 固定语料、查询与相关性判断，标注粒度及不确定项清楚；无答案查询单独统计 |
| 对照可重跑 | 相同快照和配置下生成词法/向量/混合逐条结果；输入、配置、代码版本可追踪 |
| 指标口径一致 | 指标从保存的命中与标注计算，可人工复算；不混合不同切片/对象粒度的排名结果 |
| 用户问答链路 | 输入问题、实际返回证据、答案引用和来源回看一致；答案内容另行核对，不由命中自动推出正确 |
| 失败与降级 | 无证据不伪造引用；向量不可用可明确走词法路径，并报告实际采用方式 |
| 结论边界 | 报告保留失败样本、延迟和真实/估算用量；没有提升时如实说明，不用小样本推断生产效果 |

第一组验证：先展示若干语料/查询与标注，核对数据身份、相关性粒度及指标算法；不提前宣称检索实验通过。
真实模型实验范围与成本待确定，默认确定性测试不依赖付费供应商。

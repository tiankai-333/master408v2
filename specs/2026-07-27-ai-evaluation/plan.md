# Plan — 固定 AI 评测基线

> 历史恢复：根据最终实现反推任务分组。

## Group 1：数据集和确定性评分

1. 定义 Dataset、Case 和 Result 数据结构。
2. 建立 `408-prompt-baseline-v1` 原创 JSON 数据集。
3. 实现概念覆盖、禁用表述和长度评分。
4. 实现明确标注为估算值的 Token/费用估算器。

## Group 2：运行与持久化

1. 使用 Flyway V3 建立运行和逐条结果表。
2. 实现数据集加载、运行创建、异步 Worker 和状态收敛。
3. 限制执行器线程与队列，处理任务拒绝和单例失败隔离。
4. 保存输入、输出、评分证据、Usage、费用和延迟。

## Group 3：查询与比较

1. 提供数据集列表、启动运行、查询运行和结果接口。
2. 只允许比较同一数据集版本的已完成候选。
3. 返回逐条差异和聚合指标，而不只给单一胜负结论。

## Group 4：管理端

1. 增加评测 API 与管理路由。
2. 实现异步运行状态轮询、结果明细和双候选比较页面。
3. 明确展示 estimated/provider Usage 和 N/A 费用。

## Group 5：验证

1. 测试数据集结构、评分器和估算公式。
2. 测试异步 Worker、队列拒绝、失败隔离和比较约束。
3. 验证 Flyway V3、后端测试和管理端生产构建。
